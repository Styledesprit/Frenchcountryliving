Sign in

First time here? Get your admin key (2 minutes)
  1. Press Create my key on GitHub and sign in to GitHub if it asks.
  2. The name and the Contents: Read and write permission are filled in for you. Under Repository access, choose Only select repositories and pick this site's repository. (If Contents isn’t set, find it under Repository permissions and choose Read and write.)
  3. Press Generate token, copy the key it shows (GitHub only shows it once), paste it above and press Sign in.

The key stays in this browser and is only ever sent to GitHub. Lost it, or worried someone else has it? Delete it on GitHub’s tokens page and make a new one.
