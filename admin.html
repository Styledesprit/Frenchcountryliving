Sign in

There is no password. You sign in with a GitHub access token that lets this page save to your repository. It stays in this browser and is only ever sent to GitHub.

Found automatically when this page is opened from GitHub Pages.

Advanced

Leave this unticked on a shared computer — you will be signed out when the tab closes.

Creating your token (once)

  1. Sign in to github.com. Click your profile picture (top right) → Settings.
  2. At the bottom of the left-hand menu choose Developer settings → Personal access tokens → Fine-grained tokens.
    Or go straight to github.com/settings/personal-access-tokens/new.
  3. Click Generate new token. Give it a name such as French Country Club admin and pick an expiry date (90 days is sensible; you can make a new one any time).
  4. Under Repository access choose Only select repositories and pick this site's repository.
  5. Under Permissions → Repository permissions, find Contents and set it to Read and write. Leave everything else as it is (GitHub adds “Metadata: Read” by itself).
  6. Click Generate token, then copy the token (it starts with github_pat_). GitHub only shows it once.
  7. Paste it into the box on this page and press Sign in. Tick “Keep me signed in” if this is your own computer.

Lost the token or think someone else has it? Delete it on the same GitHub page and create a new one. Nothing else needs changing.
